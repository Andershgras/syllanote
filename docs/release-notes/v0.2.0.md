# Syllanote v0.2.0

Syllanote `v0.2.0 — Writing & Organization` is the next minor release of the
local-first Windows note-taking application for students. It expands rich-text
formatting, adds persistent Section colors, and makes each Notebook's Concept
Dictionary visible from the main workspace.

> [!IMPORTANT]
> This document currently describes the `v0.2.0` release candidate. The latest
> published version remains `v0.1.0` until the release artifact, checksum, tag,
> and GitHub Release have completed Milestone 8 verification.

## Highlights

### Rich-text editor v2

- Choose from a curated set of font sizes.
- Apply strikethrough, text color, and text highlighting.
- Align paragraphs left, center, or right.
- Increase and decrease paragraph indentation.
- Clear formatting from selected text or the insertion point.
- See live word and character counts without changing stored note data.
- Reach less frequently used formatting actions through a responsive overflow
  menu when the window is narrow.

All searchable text continues to be stored separately from its RTF formatting.
Concept recognition therefore remains independent from visual formatting.

### Persistent Section colors

- Assign one of eight curated color markers to a Section.
- Change or remove the marker through the existing Section context menu.
- Retain the chosen color across restart, backup, and restore.
- Keep color supplementary to the Section name, selection, and focus states.

Existing Sections are upgraded safely with **No color** selected.

### Visible Concept Dictionary access

- Open the new **Concepts** dropdown from the horizontal workspace menu.
- Choose any Notebook directly instead of first selecting or right-clicking it.
- See which Notebook is currently selected in the dropdown.
- Open the menu with `Ctrl+Shift+D`.
- Receive clear guidance when the library does not contain a Notebook yet.

The original Notebook context-menu route remains available.

## Upgrade compatibility

- The portable build continues to use
  `%LOCALAPPDATA%\Andershgras\Syllanote` and retains the existing package
  identity and publisher metadata.
- The only database migration added after `v0.1.0` adds the optional Section
  color key. Existing notes, RTF, hierarchy, Concepts, and sort order are not
  rewritten.
- Automated coverage recreates the final `v0.1.0` schema with representative
  content and verifies both direct startup migration and backup restoration into
  `v0.2.0`.

Create a manual backup before upgrading and keep the old application folder
until the upgraded library has been checked.

## Version mapping

| Release identifier | Version |
| --- | --- |
| Planned Git tag | `v0.2.0` |
| Public product version | `0.2.0` |
| .NET assembly version | `0.2.0.0` |
| Executable file version | `0.2.0.0` |
| MSIX package manifest version | `2.0.0.0` |

The MSIX manifest uses Windows' required four-part version and a non-zero,
monotonically increasing package major. The public release remains the portable
x64 ZIP unless a trusted signing path becomes available.

The executable's informational product version also includes the source commit
as build metadata, for example `0.2.0+<commit>`. This does not change the public
release version or the `0.2.0.0` assembly and file versions.

## Known limitations

- When Windows changes between light and dark app mode while Syllanote is open,
  WinUI 3 can temporarily render user-selected foreground colors as the
  automatic theme foreground. The selected colors remain in the stored RTF and
  return after restarting Syllanote. Text highlighting remains visible.
- Only 64-bit Windows is required for the public release artifact.
- The portable executable is not code-signed and may trigger a Windows warning.
- There is no installer or automatic updater.
- Notes remain local to one Windows user profile and device; cloud sync and
  collaboration are not implemented.
- Scheduled backups, backup encryption, selective restore, import, and export
  are not implemented.

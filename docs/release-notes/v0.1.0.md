# Syllanote v0.1.0

Syllanote `v0.1.0` is the first versioned release of the local-first Windows
note-taking application for students. This release is distributed as a
self-contained x64 ZIP, so Visual Studio and a separate .NET installation are
not required.

## Highlights

- Organize notes in notebooks, sections, and pages with manual ordering.
- Write rich-text notes with headings, emphasis, bullets, and numbered lists.
- Search page titles and note content across the complete library.
- Maintain a notebook-specific concept dictionary and navigate between
  concepts and the pages that reference them.
- Create and restore versioned whole-library backups with validation and
  automatic safety-backup retention.
- Retain panel widths and window placement between sessions.
- Use the application with keyboard navigation, Narrator, display scaling,
  high contrast, and Windows dark mode.

## Download and start

Download both release assets:

- `Syllanote-v0.1.0-win-x64.zip`
- `Syllanote-v0.1.0-win-x64.zip.sha256`

Verify the SHA-256 checksum, extract the complete ZIP, and then start
`Syllanote.Desktop.exe`. Detailed installation, upgrade, backup, restore, and
troubleshooting instructions are available in the
[release guide](https://github.com/Andershgras/syllanote/blob/v0.1.0/docs/release-guide.md).

The MSIX manifest uses Windows' required four-part package version. The public
`v0.1.0` download is the portable ZIP because a trusted certificate is not
currently available for direct MSIX distribution.

## Local data and upgrades

The portable application stores its data under
`%LOCALAPPDATA%\Andershgras\Syllanote`. Extract future versions into a new
program folder and create a manual backup before upgrading. Portable and MSIX
installations use separate Windows data containers; use Syllanote backup and
restore to move a library between them.

## Known limitations

- Only 64-bit Windows is supported by this release artifact.
- The portable executable is not code-signed and may trigger a Windows warning.
- There is no installer or automatic updater.
- Notes remain local to one Windows user profile and device; cloud sync and
  collaboration are not implemented.
- Scheduled backups, backup encryption, selective restore, import, and export
  are not implemented.
